# Smart Utility Toolkit

## Course
Web Dev III (Node.js & Express Backend)

## Lab Assignment 1

This project is a Smart Utility Toolkit built using Node.js core modules.

## Features

- CLI-based calculator using `process.argv`
- Addition, subtraction, multiplication and division
- Custom `isEven` module
- Custom logger module with timestamp
- Basic HTTP server using the `http` module
- Multiple HTTP routes
- File manager using the `fs` module
- Create, read, update and delete file operations
- Random dice generator using the `crypto` module
- Dice roll history stored in a text file
