# Student Management REST API

## Web Dev III - Lab Assignment 2

A Student Management REST API built using Node.js and Express.js.

## Technologies Used

- Node.js
- Express.js
- Thunder Client
- JavaScript

## Assignment Requirements

This project implements:

- Express.js server
- REST APIs
- Student CRUD operations
- Custom logger middleware
- Modular routing
- Error handling
- Proper HTTP status codes
- Array-based JSON data
